Language layout 
The Script language LJScript is a language to describe complete print layouts for the 
Leibinger-Jet 3.  
LJScript uses only ASCII-characters and as control characters only Carriage Return (CR) 
and Line Feed (LF).  
Used are commands which have fixed relocated keywords. A parameter list follows. Further 
more the following comments can be inserted.  
Syntax: 
% comment 
KEYWORD [Parameter list] 
KEYWORD [Parameter list]       % comment 
KEYWORD [Parameter list] 
 
Keywords are always written in capital letters.  
The parameter list is specified in square brackets: [Parameter list] 
Only one keyword is permitted per line. 
 
The several parameters in the parameter list are separated by one ore more blanks, 
tabulators (Tab, Hex 09) or Carriage Return (0x0D) and Line Feed (0x0A). 
Lists and texts which occur in the parameter list are specified in parenthesis (). 
A backslash \ is prepend of the following characters if they should be part of the text: 
)    <     \     %    [   ]   results in:        \)      \<        \\        \%        \[      \] 
Every element which is declarated refers to the last defined object.  
Comments can be used. They always start with the percentage symbol % and end always at 
the end of line (CR and LF). They cannot be in the comment.  
If the parameters have a limit value MAXINT, the values margin of 32 Bit Integer is valid. It 
goes from–2.147.483.648 up to +2.147.483.647 
Floating point numbers are indicated with the decimal point. Power specifications do not 
exist.  
Time is indicated in hours (hh) and minutes (mm) and/or seconds (ss). Separators are 
indicated in colons. Example: l: hh:mm:ss 
 
Coordinate system 
X is the transport direction. Units are always strokes 
The 1. stroke has the X-coordinate X.0 
Y is the direction in which the drops are deflected. Units are ink dots  
The 1. ink dot is placed at the gutter tube and has the Y-coordinate Y.0

Beginning of Script 
Syntax: BEGINLJSCRIPT [Parameter list] 
 
Every Script has to start with this keyword. 
 
The parameter list contains only one text which has to have the version of the following 
format: 
(Va.b.c.d) 
 
Meaning: 
a=Generation 
b=Upgradings /Changes 
c=Bugfix-counter 
d=Index for special functions 
 
Further parameters can follow but they can only be used as comments.  
 
 
End of Script 
Syntax:  ENDLJSCRIPT [Parameter list] 
 
Every Script has to end with this keyword.  
The parameter list is not analyzed, can be also empty.

Encoder signals 
Encoder-Signal 
Internal = 0 
External, direction 1 (clockwise)  = 1 
External, direction 2 (anticlockwise) = 2 
External, both directions = 3 
Table 5: Encoder-Signal 
Rotation, mirror-inverted 
The fitting position of the print head is adjusted here.  
Mirror-inverted is a reflection by the Y-axis.  
Encoder resolution 
Is the resolution of the connected encoder in pulses/m.  
Shifting Change of date  
Usually the date is changed at midnight. With this parameter the time can be shifted by up to 
23 h and 59 min. The hour- and minute specifications are separated by a colon.  
Backward Lock 
Is only reasonable if the Encoder signal is on external, direction 1 or direction 2.  
Guarantees that the print will be continued at the correct position after a short operation 
against the print direction.  
 
Speed dependant output 
When the speed (from the encoder) is increasing this value, the output "Speed 
dependant output" will be switched to high signal. 
It will be switched off when the speed is falling under 10% from this value. 
From job version V01.06.00.10 the value is specified in decimeter/min so that 
the resolution will be slightly larger. In the display the value appears in m/min, 
but with a fractional point.

Flight time compensation 
 
 
 
 
Is this value higher than zero, the PrintGo-delay is reduced depending on the speed. Due to 
this you can obtain that the print is always at the same place even at different speeds. If the 
value is 0, then the function is turned off.  
 
Sensor Monitoring 
Turned off = 0 
Turned on = 1 
With this switch 3 monitoring (controls) will be activated: 
1. PrintGo Sensor 
For this monitoring a 2. PrintGo Sensor will be used. This must be connected to the PrintGo 
Gate input. Both sensors must be PNP sensors. 
Turned off = 0 
Turned on > 0

The sensors must be adjusted in this way, that the signals of both sensors overlap for a short 
time. 
An error will be generated, when one of the 2 sensors has not switched, when the other has 
switched on and off. 
 
Monitoring 2 and 3: 
An error will be generated too, when there is a PrintGo signal and 
- the Production speed is 0 (no encoder pulses, monitoring 2)  or 
- the print is not started (monitoring 3). 
 
 
Stroke monitoring 
Turned off = 0 
Turned on = 1 
 
If the stroke frequency is higher than the Leibinger-Jet possible maximum stroke frequency, 
an error is caused. The print will not be stopped.  
 
PrintGo monitoring 
Turned off = 0 
Turned off = 1 
 
If a further PrintGo-signal appears during the delay or during the print, an error is caused.  
The print will be not stopped. 
 
PGHoldOff 
Value to get a minimum distance of print to print (e.g. for additional printmarks) that means if 
additional PrintGo-signals appear within the holdoff distance, they will be ignored.  
IdentNr CameraJob 
-1 = means, that no camera will be used.  
0 = means, that the Ljet3 job has no allocation to a configurated job on the camera  
The Ids (1 – 2^31) will be generated on the camera host and are downloaded from the Ljet3. 
 
CameraJob Name 
The name will be generated on the camera host and downloaded from the LJet3. 
 
Max. products between LJ3 and camera 
Control value (Trigger control): Maximum number of products, which are allowed between 
print head and the camera. 
Product offset between LJ3 and camera 
Number of products as a fix value, which are between the current printed product and the 
camera.

Cameratrigger-delay 
The trigger signal for the connected camera will be delayed with this value. 
The unit is µm. 
 
Print stop interrupts print-out immediately 
Can have the value 0 or 1: 
0: The print stop will be done after the Text-End. The result is that the Text will 
not be truncated. 
1: The print stop will be done immediately 
 
Indexcounter of previous camera job data 
If no Camera using, the value has to be 0. 
The index is always counted by updating a camera job. This is an information for the 
JETvisio program on the PC. The Index will be compare with the actual loaded job on 
the JETvisio program. If it is higher, the job will be also updated on the PC. 
 
Plotmode 
In the Plotmode the Leibinger-Jet prints always only the first stroke (Stroke 1). 
The Plotmode will be stopped with a Printstop or a change of the Job. 
 
Attention: In the Plotmode the Leibinger-Jet is not able to make a phasing.

Syntax: CNT [Parameter list] 
 
Every counter which is declared refers to the last defined object. The counter is placed at the 
position where you can find the object {c} in the text.  
 
The parameter list contains the following parameters in this order:  
  Values margin 
1 Number of digits 1 - 10 
2 Start value 0 – 9.999.999.999 
3 Initial value 0 – 9.999.999.999 
4 End value 0 – 9.999.999.999 
5 Increment -100 ... +100 
6 Repetitions 1 - 101 
7 Leading zeros 0   1 
8 Counting event 0 - 2 
9 Counter basis 10 (currently only 10  
permitted ) 
10 Reset 0 - 2 
11 LoopMode 0  1  2 
12 Repetitor 0 - 100 
13 Don’t print 0  1 
14 Global counter 0  1 
Table 8: Declaration of counter 
 
Start value: 
This value the counter uses when he reached the end value. 
 
Initialisation value: 
This value the counter uses after a jobload or a counter reset.  
 
End value: 
When the counter reached this value, he begins with the start value. 
Increment: 
This value will be added to the counter value when the count event happened. 
Repetitions: 
Repetition of the actual counter value.  
With a repetition of 3 the result can be like this: 1 1 1 2 2 2 3 3 3 ... 
 
Counting event: 
After PrintGo = 0 
After PrintActive = 1

With ext. counting input = 2 
 
After PrintGo: 
It is counted after every PrintGo signal irrespectively of if a print has been generated or not 
(similar to MeterGo - funktion at LJ2)  
 
After PrintActive: 
It is counted further after every started print (standard).  
 
With ext. Counting input 
It is counted further with every rising edge at the X4.2 input.  
 
Reset  
Manual = 0 
PC = 1 
External signal = 2 
 
Manually: 
Counter is reset by manual operation or by command from external interface. 
 
PC  
Counter is reset synchronously to the product counter, that means if it is reset to 0 by the 
operator, also the object counter is reset.  
 
External signal  
Counter is reset to X4.1 after rising edge.  
 
LoopMode  
Print Stop at the end = 0 
Loop = 1 
Up-/Down = 2 (Not supported by GUI)  
Repetitor  
Actual value of the done repetitions. 
Don’t print 
When the counter is used for a control function, it can be, that he should not be printed. Then 
this value is set to 1. 
 
Global counter 
When this value is set to 1, this counter is a global counter. In the Jet3 exists one global 
counter. Its value can be accessed over this button.

Printing text 
The text which is shown in the parenthesis is printed. The parenthesis will be not printed.  
Character gap 
Shows the distance between the several characters. Default value is 1.  
Rotation, Mirror-inverted 
Every object can be rotated/mirrored.  
Mirror-inverted is a reflection by the Y-axis. 
Proportional: 
Every font can be printed proportional or not proportional. In principle the fonts are applied 
proportional.  
For non-proportional print the RIP (printer) inserts empty strokes up to the maximum 
character width. They will be inserted that the character is placed centered.  
User-specific graphics are stored in one or more special fonts.  
Bold text: 
Every stroke is printed as often as given by the indicated number, but every stroke is printed 
separately. The character width increases accordingly. The bold text has no influence on the 
maximum printing speed.  
Contrast print: 
Every stroke is printed as often as given by the indicated number, but the additional strokes 
are printed on top of the previous stroke. The character width does not increase, but the 
maximum printing speed reduces.  
This parameter will be taken over automatically to all objects, which are located in this X-
area. The highest contrast print is carried out.  
Inverse: 
All pixels are inverted.  
An ink dot will not become an ink gap. 
an ink gap dot will become an ink dot. 
If required an additional frame is drawn around the object (e.g. for texts, special barcode 
types)  
 
Alternate: 
After every PrintGo the print it is turned by 180°.
